## Thesis

反省的自己形成能力を持つだけでは、AIを責任主体とは認められない。

## Argument

AIが自らの選好傾向性を二階的に評価・修正できたとしても、すべての行為が外部promptによって開始されるなら、AI自身が行為の起点になっているとは言い難い。

責任主体には、

environment / memory
→ salience
→ endogenous goal formation
→ action initiation

が必要である。

## Consequence

Sourcehoodを人格形成の「究極的起源」に求めるのではなく、主体が現在の経験史・価値体系からgoalを形成し、行為系列を開始できることとして再構成する可能性がある。
