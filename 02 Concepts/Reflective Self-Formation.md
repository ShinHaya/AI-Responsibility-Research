# Reflective Self-Formation

主体が自らの一次的欲求、動機、選好、価値、習慣、規範的基準を対象化し、承認・拒否・修正し、その結果を将来の自己へ持続的に組み込む能力。

## Beyond Second-Order Volition

Frankfurtのsecond-order volitionは出発点だが、現在の二階的欲求へのidentificationだけでは不十分である。

```text
first-order motive
  -> second-order evaluation
  -> provisional endorsement
  -> action
  -> new experience and criticism
  -> renewed reflection
  -> possible revision
```

現在の二階的方針も将来の反省に開かれていなければならない。→ [[Second-Order Volition Requires Open-Ended Revisability]]

## Passive Preconditions

反省は中立な自己表象から始まらない。何が問題として現れ、どの価値が自明に感じられ、どのalternative selfが想像可能かは、[[Passive Synthesis]]、[[Habituality]]、[[Sedimentation]]によって先構造化されている。

したがって自己形成は次の二層を持つ。

```text
genetic-passive formation
  -> salience / inherited values / habitual style
  -> reflective activation
  -> criticism and self-variation
  -> practical revision
  -> sedimentation into future agency
```

## Intersubjective Correction

主体は自分の沈殿したbiasを単独では発見できないことがある。[[Intersubjective Agency]]における他者の批判は、背景化された規範を顕在化し、別のperspectiveを開く。自己形成は他者から独立した自己創造ではなく、他者への応答を通じた自己更新でもある。

## AI Requirements

AIが機能的なreflective self-formationを持つには、少なくとも以下が必要である。

1. 自らの選好・goal・評価基準を表象できる。
2. counterfactualな自己・価値構造を比較できる。
3. 現在の基準そのものを理由に応じて修正できる。
4. 修正がmemoryだけでなく将来のsalience、goal形成、行為へ[[Sedimentation|沈殿]]する。
5. 後の経験と他者の批判によって再度修正できる。
6. 修正履歴が[[AI Individuation|このAI]]の経験史として追跡できる。

## Not Sufficient Alone

反省的自己形成だけでは行為主体にならない。[[Agentive Action Initiation]]、[[Genetic and Diachronic Agency]]、[[Intersubjective Agency]]との統合が必要である。

## Active-Inference Meta-Control

[[sandved-smithComputationalPhenomenologyMental2021]]は、perception、attention、meta-awarenessの三階層を用い、上位policyが下位推論のprecisionを調整するmental actionをモデル化する。この構造は、自己状態へのaccess、monitoring、下位過程への介入という[[Reflective Self-Formation]]の実装可能な部品を与える。

しかし、注意状態をnoticeして修正できることと、自らのpreferenceや価値を理由に照らして承認・拒否できることは異なる。責任に必要な反省は少なくとも、(1) preferenceへの二階アクセス、(2) counterfactualな評価、(3) revision policy自体の再検討、(4) 改訂結果の[[Sedimentation]]を必要とする。したがってmeta-awarenessは反省的自己形成の証拠候補であって、その十分条件ではない。

## Mechanistic Access: Introspection and Workspace

[[lindseyEmergentIntrospectiveAwareness2026a]]はconcept injectionを用い、一部のLLMが内部状態を限定的に検出・報告し、prior intentionと外部prefillを区別し、指示によって内部表現を調整できることを示す。[[gurneeVerbalizableRepresentationsForm2026]]のJ-spaceは、report、holding、silent reasoning、flexible downstream useに利用されるworkspace-like representationsを同定する。

これらは反省的agencyの**access layer**を実装できる証拠である。ただし次の段階を区別する必要がある。

```text
state access
  -> accurate self-report
  -> local state control
  -> value-based evaluation
  -> preference revision
  -> persistent self-formation
  -> normative answerability
```

現在のmechanistic evidenceは主に前三段階までを支持する。[[Reflective Self-Formation]]には、評価基準自体の[[Normative Contestability]]と、revisionが[[Genetic and Diachronic Agency]]へ沈殿することが追加で必要である。
