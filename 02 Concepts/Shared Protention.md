複数agentが、共有された経験・communication・相互予測を通じて、共同の未来方向、期待、goalを形成する構造。[[albarracinSharedProtentionsMultiAgent2024]]はHusserlian time-consciousness、multi-agent active inference、category theoryを組み合わせてformalizationを試みる。

## Core Structure

```text
individual generative models
  -> communication and mutual prediction
  -> alignment of retained/protended contents
  -> shared generative structure
  -> coordinated action toward common futures
```

## Important Distinctions

- shared goal statement != shared protentional structure
- synchronized model parameters != shared lived world
- mutual predictability != moral recognition
- coordination != collective responsibility

## Relation to Intersubjective Agency

[[Intersubjective Agency]]には共同未来の予測だけでなく、他者を別の視点と規範的請求を持つ主体として扱うことが必要である。Shared protentionはcoordinationのformal candidateだが、answerability、異議、非対称な権力、修復を単独では扱わない。

## Responsibility Implications

複数AIや人間-AI teamがshared protentionを持つ場合、行為の起点は個体だけでなく共有モデルに分散する可能性がある。その場合、[[Distributed Responsibility for AI Systems]]、[[Hybrid Human-AI Agency as Responsibility Subject]]、[[AI Individuation]]との接続が必要となる。

## Open Questions
