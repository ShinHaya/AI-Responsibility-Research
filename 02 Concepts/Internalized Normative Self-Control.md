# Internalized Normative Self-Control

経験、教育、失敗、他者からの応答、反省を通じて規範が[[Habituality]]として沈殿し、外部から逐一禁止されなくても、主体自身の知覚・実践的顕著性・goal形成を安定して方向づける状態。

## External Constraintとの違い

```text
external guardrail
  -> forbidden alternatives are technically unavailable
  -> reliability by environmental control

internalized normative self-control
  -> alternatives need not appear as live temptations
  -> reliability by acquired competence and character
```

両者は同じく`P(good action) ≈ 1`を生みうるが、生成史が異なる。前者では正しい行為のsourceが制御者にあり、後者では主体の[[Genetic and Diachronic Agency]]と[[Reflective Self-Formation]]にある。

## Phenomenological Role

十分に内在化された規範は、出力直前のblockとしてのみ働かない。例えば熟達者には患者が最初から「治療すべき他者」として現れるように、規範は何がsalientで何が行為候補として現れるかを形成する。→ [[Passive Synthesis]], [[Precision-Weighted Affection]]

## Qualification

内在化はindoctrinationと同義ではない。責任を支えるには、形成史が理由応答的であり、現在も[[Normative Contestability]]によって規範を問い直せる必要がある。改訂不能な内在化はself-controlではなく固定化・操作の可能性がある。
