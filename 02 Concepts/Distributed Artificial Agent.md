# Distributed Artificial Agent

複数のphysical process、model instance、memory service、tool executorが、統一された記憶統治、goal形成、反省、policy control、action initiation、answerabilityを実現することで、一つのagent boundaryとして機能する人工主体。

## Individuation Test

単なるnetwork connectionまたはshared database accessでは足りない。少なくとも次を問う。

1. 競合するmemoryやgoalを誰がratify・reviseするか。
2. system全体に一貫したpolicyを形成するcontrol centerまたはgovernance processがあるか。
3. 各instanceが独立してrefuse・endorse・actできるか。
4. 一つの行為についてsystem全体が理由を提示し、訂正を引き受けられるか。
5. component交換後も[[Individuated Causal-Historical Continuity]]が保たれるか。

## Responsibility

統一性が成立する場合、component instanceだけを処罰してもresponsibility subjectを取り違える可能性がある。責任はdistributed agent、deploying organization、個々のcontributorsへcausal contributionとnormative controlに応じて配分する。

統一性が成立しない場合はcollective actionまたはdistributed responsibilityの問題であり、一つのagentと数えてはならない。
