# Sedimentation

過去の経験や能動的成果が消失せず、背景化された獲得物として後の経験・判断・行為を先構造化すること。沈殿は情報保存ではなく、主体の将来の現れ方と実践的傾向を変える。

## Database vs Sedimentation

```text
database memory:
past -> stored proposition -> optional retrieval

sedimentation:
past experience -> transformed subject -> changed future horizon
```

自己修正が会話中の発話に留まり、次sessionのattentionやgoal formationに影響しないなら、それは通時的な自己形成ではない。

## Primary and Secondary Passivity

受動的に与えられる連合・触発だけでなく、過去の能動的判断やcommitmentが後に背景化し、自明な傾向として働く二次的受動性が重要である。責任論では、過去に承認した価値が現在の判断を自動的に方向づける構造を説明できる。

## Sedimentation Is Not Irreversibility

```text
sedimentation != permanent fixation
```

沈殿は安定性を与えるが、新しい経験、他者の異議、内部矛盾によって再活性化され、反省・更新されうる。責任的主体性には、沈殿と再活性化の両方が必要である。

## Responsibility Relevance

- 過去の反省結果を将来の行為へ持続させる。
- 行為を一時点の出力でなく人格史の表現として理解させる。
- biasや不正な規範が無自覚に働く可能性を示す。
- 他者による批判が背景化された規範を顕在化させる役割を説明する。

## AI Criteria

AIにおけるfunctional sedimentationを主張するには、少なくとも以下を示す必要がある。

1. 更新が将来の知覚・顕著性・評価・goal形成へ横断的に影響する。
2. その更新が当該AIの個体化された履歴に由来する。
3. 更新結果が安定しつつ、理由に応じて再活性化・改訂可能である。
4. どの経験が沈殿したかを責任説明の中で追跡できる。
